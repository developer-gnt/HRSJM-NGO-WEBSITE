## Files to create (3 files + 1 asset copy)

1. **`public/rights-hero-bg.png`** — copy the provided generated image (from the image cache) into `public/` under a new name so the existing `know-your-rights-bg.png` (Lady Justice artwork, used by the home page) stays untouched. Rendered via `next/image` (`fill`, `sizes="100vw"`, **`preload`** — `priority` is deprecated in this Next 16 codebase), so the 2.4 MB source gets optimized at serve time.

2. **`src/app/rights/page.tsx`** — thin Server Component page, matching `contact/page.tsx` pattern:
   - `export const metadata: Metadata = { title: "Know Your Rights", description: ... }` (title template appends "| HRSJM" automatically)
   - Renders **only** `<RightsHero />` — no placeholder sections below, navbar/footer come from root layout.

3. **`src/components/rights/RightsHero.tsx`** — self-contained **Server Component** (no `"use client"` needed; all animations are pure CSS, matching the site's reduced-motion-gated approach). Structure:
   - Background image layer + navy left gradient scrim (strong left → transparent right, like `contact.module.css` hero) + subtle top/bottom shading — left 45–50% stays dark for text, architecture/people remain visible right.
   - **Breadcrumb** (top-left, inside hero): `Home` (subtle link) › `Know Your Rights` (readable, `aria-current="page"`), chevron separator (project's `Icon` chevronRight), small non-dominant typography.
   - **Eyebrow**: small gold circle accent + `KNOW YOUR RIGHTS` (uppercase, 0.2em tracking, 12px — matches existing eyebrow pattern).
   - **H1** in `--font-display` (Cormorant Garamond): "Rights Create" white / "Stronger Communities." gold (block span), large editorial clamp sizing.
   - **Description**: exact provided copy, constrained to ~2 lines, soft white.
   - **CTAs**: primary gold button "Explore Your Rights →" (navy text, rounded, subtle hover lift; arrow via existing `Icon` "arrow") and secondary "▷ Watch Video" (transparent, thin light border, play icon). Both are `Link`s pointing to future-section anchors `#explore-rights` / `#featured-video` (inert until those sections are built in later steps — noted assumption, no dead custom JS).
   - **Handwritten note** (top-right, absolute): Caveat via `--font-script`, dark ink color, 5 lines "Awareness. / Rights. / Action. / A Fairer / Tomorrow.", slight rotation, small gold hand-drawn underline SVG (reusing the AboutHero underline stroke pattern). Sized modestly.
   - **Bottom feature strip**: 4 evenly distributed items with gold-outlined circular icon rings (larger variant of the existing `iconRing` pattern): `bookOpen` "Learn Your Rights", `fileText` "Understand Real Situations", `hand` "Know How to Get Help", `shieldCheck` "Build a Safer Community" — all icons already exist in `Icon.tsx`, no icon library changes. Subtle top border separates it from hero content.
   - **Animations**: CSS keyframe fade + upward stagger (breadcrumb → eyebrow → heading → description → buttons → note → feature items) with `animation-delay`; fully disabled under `prefers-reduced-motion` (project convention).

4. **`src/components/rights/rights.module.css`** — co-located CSS Module using existing global tokens (`--color-navy`, `--color-gold`, `--font-display`, `--font-script`, `--container`, `--page-padding`), section comment banners, breakpoints **1023px / 639px** per project convention:
   - Tablet: smaller heading, feature strip 2×2.
   - Mobile: heading scales down, CTAs stack, handwritten note moves into flow (right-aligned, below CTAs — no overlap), feature strip becomes 2×2/stacked, background `background-position` shifted right so dome + people stay visible, no horizontal overflow.
